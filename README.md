## Що всередині

Усі курси побудовані однаково. Кожен урок має таку структуру:

- 🎯 **Мета уроку** — що учень вміє після нього
- 📘 **Ключові поняття** — нові терміни простими словами
- 📖 **Теорія з ілюстраціями** — схеми, таблиці, аналогії
- ▶️ **Живі приклади коду** — кнопка «Запустити» показує результат і консоль прямо на сторінці
- 🧪 **«Спробуй сам»** — редактор, де можна змінювати код і бачити результат наживо
- 🏗️ **Крок проєкту «Полиця»** — кожен урок додає одну деталь до власного сайту учня
- 🔍 **«Перевір у браузері»** — що подивитися в DevTools
- 🏠 **Домашнє завдання** трьох рівнів: Базовий / Середній / Зірочка ⭐
- ✅ **Самоперевірка** — 3 питання з поясненнями

Після кожного блоку — **контрольна** з оцінкою за 12-бальною шкалою.

### Курси Google Sheets і Python

- **Google Sheets (14):** основи й форматування → формули й функції → IF/COUNTIF → фільтри й перевірка даних → XLOOKUP → текст і дати → діаграми → зведені таблиці → Google Forms → UNIQUE/FILTER/QUERY → Apps Script і AI → дашборд. Наочні «живі» макети таблиць з рядком формул.
- **Python (24):** print і змінні → input і f-рядки → умови → while → for → рядки → вікторина → списки → функції → словники → множини → модулі й текстова пригода → файли → CSV → try/except → pandas → groupby → matplotlib → Google Sheets і API → AI → «Дослідження класу». Кожен приклад запускається в браузері (Pyodide), навіть pandas і графіки; є пісочниці «Спробуй сам» з полем для input().

## Учням

1. Відкрий посилання на свою версію курсу (вчитель скаже, яку).
2. Перед першим уроком пройди розділ **«Де працювати»** і налаштуй VS Code.
3. Після уроку повтори теорію вдома: приклади можна запускати, а в блоках «Спробуй сам» — експериментувати.
4. Домашні завдання — у розділі **«Домашні завдання»**. Галочки й пройдені уроки зберігаються в браузері на твоєму пристрої.
5. Застряг? Дивись **«Як перевіряти сторінку»** і **«Словник термінів»**.

## Вчителю

- Учням — головна сторінка сайту: там **учнівські видання** без вкладки «Для вчителя».
- **Видання для вчителя** — за посиланням «🔒 Вхід для вчителя» (`/teacher/`). Вони **зашифровані паролем** (AES-256): без пароля вміст файлів у `teacher/` прочитати неможливо, навіть з публічного репозиторію. Можна поставити «Запам'ятати на цьому пристрої».
- **Контрольні приховані від учнів.** В учнівських виданнях питання контрольних зашифровані, їх не видно навіть у коді сторінки. Щоб відкрити контрольну, у виданні для вчителя (вкладка «🧑‍🏫 Для вчителя» або сторінка контрольної) увімкніть перемикач **«Видимість контрольних для учнів»**. Перемикач записує ключ у `config/tests.json`, і за 1–2 хвилини контрольна з'являється в учнів. Вимкнули — ховається знову. Для перемикача один раз потрібен особистий ключ GitHub (інструкція — біля перемикача).
- Змінити пароль: зібрати курси й перешифрувати новим паролем (див. нижче). Сам пароль ніде в репозиторії не зберігається.
- Відповіді до тестів закладені в сторінку. Контрольні, що йдуть в оцінку, краще проводити на уроці.

## Як оновити курс

Весь вміст лежить у `src/` як Python-дані, а сторінки збираються одним скриптом.

```bash
export TEACHER_PASSWORD='пароль'   # потрібен і для шифрування контрольних
python3 src/build.py         # веб-курси (25 і 38)
python3 src/build_data.py    # Google Sheets і Python
python3 src/protect.py       # зашифрувати видання для вчителя
git add -A && git commit -m "Опис змін" && git push
```

Після push сайт на GitHub Pages оновиться за 1–2 хвилини.

Якщо змінити пароль вчителя, ключі контрольних теж зміняться: після нового збирання відкриті контрольні треба буде увімкнути перемикачем ще раз.

|---|---|

| `src/c38.py` | Версія на 38: які уроки розділено й нові уроки |
| `src/c5.py` | Контрольні |
| `src/c6.py` | Сторінки: «Де працювати», «Як перевіряти», «Проєкт», «Для вчителя», «Довідник тегів» |
| `src/gloss.py` | Словник термінів |

| `src/svgs.py` | Ілюстрації (SVG) |
| `src/shell.html` | Оформлення й логіка сайту (CSS + JS) |
| `src/build.py` | Збирання веб-курсів |
| `src/s14.py`, `src/d1.py` | Курс Google Sheets |
| `src/p1.py` … `src/p3.py` | Курс Python |
| `src/dpages.py`, `src/dpages2.py` | Тести, словники, довідники й сторінки курсів Sheets і Python |

Номери уроків у тексті не пишуться вручну: замість них використовуються мітки на кшталт `⟦supa⟧` чи `⟦r:js⟧`, які скрипт сам замінює на правильні номери для кожної версії.

Ідеї розвитку — у папці [`docs/`](docs/): загальний план [IDEAS.md](docs/IDEAS.md) і окремі ідеї.
