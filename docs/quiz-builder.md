# Ідея: конструктор тестів і квізів

> Вчитель дає матеріали — система готує тести, роздає їх учням і сама збирає результати.

## Проблема

Підготувати якісний тест до кожної теми — це години роботи. Перевірити 60 робіт — ще більше. А потім треба перенести оцінки в журнал і зрозуміти, яку тему клас не засвоїв.

## Як це працює (сценарій вчителя)

1. **Завантажуєш матеріали**: підручник (PDF), конспекти, презентації або просто посилання.
2. **Завантажуєш календарно-тематичний план** на рік: номер уроку, дата, тема, очікувані результати (з Word, Excel, Google Sheets або PDF).
3. **Система розбиває план на теми** й до кожної знаходить потрібні сторінки підручника.
4. **Генерує тести** до кожної теми: ти обираєш кількість питань, складність і типи.
5. **Переглядаєш і редагуєш**: прибираєш погані питання, правиш формулювання, позначаєш «перевірено».
6. **Публікуєш**: посилання або QR-код для класу, можна обмежити час і дату.
7. **Отримуєш результати автоматично**: таблиця «учень × питання», оцінка за 12-бальною шкалою, найскладніші питання й теми.

## Типи завдань

| Тип | Перевірка |
|---|---|
| Один правильний варіант | автоматично |
| Кілька правильних варіантів | автоматично (часткові бали) |
| Правда / неправда | автоматично |
| Встановити відповідність | автоматично |
| Розташувати в правильному порядку | автоматично |
| Пропущене слово / коротка відповідь | автоматично (кілька допустимих варіантів) |
| Числова відповідь | автоматично (з похибкою) |
| Код (HTML/CSS/JS/Python) | автоматично — запуск у пісочниці й перевірка результату |
| Розгорнута відповідь | AI пропонує оцінку й коментар → вчитель підтверджує |

## Режими

- **Самоперевірка** — після уроку, без оцінки, з поясненнями (як у «Веб-майстерні»).
- **Контрольна** — з таймером, перемішуванням питань і варіантів, одна спроба.
- **Квіз на уроці** — як Kahoot: питання на проєкторі, учні відповідають з телефонів, рейтинг у реальному часі.
- **Варіанти** — кожен учень отримує свій набір питань з банку (менше списування).
- **Повторення** — перед контрольною система збирає питання, на які клас відповідав найгірше.

## Для учня

- Вхід за кодом класу + ім'я (без реєстрації) або через Google-акаунт школи.
- Після тесту: бал, правильні відповіді (якщо вчитель дозволив), пояснення і посилання на урок.
- Особиста сторінка прогресу: теми, які «горять» червоним.

## Для вчителя: аналітика

- Журнал: учні × тести з оцінками за 12-бальною шкалою.
- Теплова карта «учень × тема» — хто що не засвоїв.
- Найскладніші питання (можливо, питання погане, а не учні).
- Експорт у Google Sheets / Excel; у перспективі — перенесення в електронний журнал.

## Як побудувати

| Частина | Варіант |
|---|---|
| Фронтенд | Vue 3 або той самий рушій курсу (HTML + JS) |
| База й авторизація | Supabase: таблиці `classes`, `students`, `topics`, `questions`, `tests`, `attempts`, `answers` + RLS |
| Розбір PDF / DOCX / XLSX | серверна функція (Supabase Edge Function або Node.js) |
| Генерація питань | AI-модель через API: тема + фрагмент підручника → питання в JSON за схемою |
| Перевірка коду | пісочниця в браузері (iframe для веба, Pyodide для Python) |
| Квіз у реальному часі | Supabase Realtime |

### Схема даних (чернетка)

```
classes(id, name, teacher_id, join_code)
students(id, class_id, name)
topics(id, course, lesson_no, date, title, outcomes, source_pages)
questions(id, topic_id, type, text, options jsonb, answer jsonb, explanation, difficulty, status: draft|approved)
tests(id, class_id, title, mode, question_ids, opens_at, closes_at, time_limit)
attempts(id, test_id, student_id, started_at, finished_at, score, grade12)
answers(id, attempt_id, question_id, value jsonb, is_correct, points)
```

## Якість і безпека

- **Кожне питання від AI — чернетка**, доки вчитель не позначить «перевірено». AI може помилятися або вигадувати факти.
- Генерація лише з **завантажених матеріалів** (питання посилається на сторінку підручника), а не «з голови» моделі.
- **Мінімум персональних даних** учнів: ім'я або псевдонім, без телефонів і адрес.
- Підручники — лише для внутрішнього використання вчителем, без публікації тексту.
- Відповіді на контрольні перевіряються **на сервері** (а не в коді сторінки, як зараз у курсі).

## Етапи

1. **MVP (🟡 кілька днів):** вчитель вставляє тему й текст → AI генерує 10 питань → редагування → посилання для учнів → результати в таблиці Supabase / Google Sheets.
2. **План на рік (🟡):** імпорт календарного плану, банк питань по темах, тести за розкладом.
3. **Підручник (🔴):** завантаження PDF, пошук потрібних сторінок для кожної теми.
4. **Аналітика (🟡):** теплова карта, найскладніші питання, експорт.
5. **Квіз наживо (🔴):** режим Kahoot з Realtime.
6. **Задачі з кодом (🔴):** автоперевірка HTML/CSS/JS/Python.

## Звідки почати

Найшвидший шлях до користі — MVP на Google Forms: AI генерує питання у форматі, який Apps Script перетворює на Google Form у режимі тесту. Результати й автоматична оцінка — вбудовані в Forms, журнал — у Sheets. Потім, коли зрозуміло, що потрібно, переходити на власний застосунок.
